# Clipboard Translate

[![Language: Python](https://img.shields.io/badge/Language-Python-3776AB?style=for-the-badge&logo=python&logoColor=white)](#)

## Usage
- Copy some text in a different language

- Script detects it and translates automatically

- Translated result prints to console and pops up as a notification

- Use ^c to exit (ctrl + C)

- To veiw log open log.txt 

### Made for use in Rust — right-click on any message and click “Copy,” and it will auto-translate it. This can also be used in any chats that allow copying messages
